# Зачётка

Тренажёр для подготовки к зачётам и экзаменам: все дисциплины, вопросы, теория и тренажёр по бухучёту — в одном файле `index.html`.

- Открывается в браузере без сервера и без интернета (шрифты подгружаются, если есть сеть).
- Прогресс сохраняется в браузере устройства, на котором вы занимаетесь.
- Ссылка для телефона — через GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
